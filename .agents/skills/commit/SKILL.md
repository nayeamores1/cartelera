# Adaptador para Codex

Leer AGENTS.md de la raíz y `.claude/skills/commit/SKILL.md` del mismo repositorio, relativo a la raíz Git, no a esta carpeta. Aplicar ese procedimiento compartido completo. La solicitud humana debe autorizar el commit y sus cambios deben estar revisados; preparar el harness no autoriza commits. Nunca leer .env ni hacer push como efecto secundario.

Este archivo permite descubrimiento en clientes con soporte de skills de proyecto; no asegura un comando /commit ni prueba carga automática en una sesión ya abierta. Si no se descubre, la persona puede pedir explícitamente leer el procedimiento por su ruta.
